# QLDA - Hệ thống theo dõi giá trị chuyển nhượng cầu thủ

Đồ án môn Quản lý dự án CNTT.

## Công nghệ
- Frontend: ReactJS + Vite
- Backend: Node.js + Express + Prisma
- Database: SQL Server 2022

## Cấu trúc
- `backend/` — API Node.js
- `frontend/` — Giao diện ReactJS
- `database/` — Script tạo bảng và import dữ liệu
- `docs/` — Đặc tả, use case, class diagram

## Nguồn dữ liệu
Dataset mở `dcaribou/transfermarkt-datasets` (giấy phép CC0).
Phạm vi: cầu thủ giải Ngoại hạng Anh.
